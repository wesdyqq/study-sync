### Сервисное программное обеспечение

Основное назначение системных программ, или [[Утилита|утилит]], состоит в автоматизации работ по проверке, наладке и настройке компьютерной системы.⁠​‌​‌​​‌‌​‌​​​​​‌​‌​​​‌‌​​‌​​​​​‌​‌​‌​‌​‌​‌​‌​‌​​​‌​​‌​​​​​‌‌​​​‌‌‌​‌​​​​‌​‌​​​​‌‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​‌‌​​​​‌​​‌‌​‌​​​‌‌​​​‌‌​​‌‌​‌​​​‌‌​​​‌‌‌‌‌‌​‌​​​​‌​‌‌‌‌​‌‌‌​‌​​​​‌​‌‌‌‌‌​‌‌​‌​​​​‌​‌‌​​‌​​​‌​​​​​‌‌​‌​​​​‌​​‌‌​‌​‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​​‌​‌‌‌‌​​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​​‌​‌‌‌​‌‌‌‌​‌​​​‌‌​​​‌‌​​​​‌​​​​​‌‌​‌​​​​‌​‌​​​​‌‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​​‌​‌‌‌‌​​‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​‌‌​​​​​‌​‌‌​‌​​​​‌​‌‌‌‌‌​‌‌​‌​​​​‌​‌‌​​‌​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​‌‌​​​​‌‌‌​‌‌‌‌‌​​‌‌​‌​​​​‌​​‌‌​​​‌‌​‌​​​​‌​‌‌‌‌​‌‌‌​‌​​​‌‌​​​​‌​​‌‌​‌​​​​‌​‌‌‌‌‌​‌‌​‌​​​‌‌​​​​​​​‌‌​‌​​​​‌​‌‌‌‌​​‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​‌‌​​​​​‌​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​​‌​‌‌‌​‌​‌‌​‌​​​​‌​‌‌​​​​​​‌​‌‌‌‌‌‌​‌​​​​‌​​‌‌​‌​‌‌​‌​​​​‌​‌‌‌‌‌​‌‌​‌​​​​‌​‌‌‌‌​‌‌‌​‌​​​‌‌​​​​​​‌‌‌​‌​​​​‌​‌‌‌‌‌‌‌‌​‌​​​​‌​‌‌​‌​‌‌‌​‌​​​​‌​‌‌‌​‌​‌‌​‌​​​‌‌​​​​​‌​‌‌​‌​​​‌‌​​​‌​‌‌​​‌​​​​​‌‌​‌​​​​‌​‌‌‌​‌‌‌‌​‌​​​​‌​‌‌​‌​‌‌‌​‌​​​​‌​‌‌‌​‌​‌‌​‌​​​‌‌​​​​‌‌​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​​‌​‌‌‌​​‌​​‌​‌‌‌‌‌‌​‌​​​​‌​​‌‌​​​‌‌​‌​​​​‌​‌‌‌‌​‌‌‌​‌​​​‌‌​​​​‌​​‌‌​‌​​​​‌​‌‌‌‌‌​‌‌​‌​​​‌‌​​​​​​​‌‌​‌​​​​‌​‌‌‌‌​​‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​‌‌​​​​‌‌​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​‌‌​​​‌‌‌‌​​‌​​​​​‌‌​‌​​​​‌​‌‌‌​​​​​‌​​​​​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​​‌​‌‌‌‌​‌‌‌​‌​​​‌‌​​​​‌​​‌‌​‌​​​​‌​‌‌‌‌‌​‌‌​‌​​​‌‌​​​​​​​‌‌​‌​​​​‌​‌‌‌‌​​‌‌​‌​​​​‌​‌‌​​​​‌‌​‌​​​‌‌​​​​​‌​‌‌​‌​​​​‌​‌‌‌​​​‌‌​‌​​​​‌​‌‌‌​‌​‌‌​‌​​​​‌​‌‌​​​​​​‌​​​​​​​‌‌​​​​​​‌‌​‌​‌​​‌​‌‌‌​​​‌‌​​​‌​​‌‌​​​‌​​‌​‌‌‌​​​‌‌​​‌​​​‌‌​‌‌​​​‌​‌‌‌​​‌‌​‌‌​‌​‌‌​​‌​​​‌‌​​​​‌‌‌​​‌‌‌‌‌‌‌​‌​​​‌​‌‌​‌​‌⁣

**Функции утилит:**

- мониторинг показателей датчиков и производительности оборудования;
- управление программами оборудования;
- контроль показателей и проверка ссылочной целостности;
- расширение возможностей [[ОС|операционной системы]].

**Классификация сервисного ПО:**

1. Диспетчеры файлов (файловые менеджеры).
	- Используются для выполнения операций, связанных с обслуживанием [[Файловая система|файловой системы]].
2. Средства для сжатия данных (архиваторы).
3. Средства диагностики.
4. Средства контроля или мониторинга.
	- Отслеживают процессы, происходящие в компьютерной системе, либо в режиме реального времени, либо в режиме записи результатов работы в специальном протокольном файле.
5. Мониторы установки.
	- Специальные программы, предназначенные для контроля над установкой [[Программное обеспечение|программного обеспечения]].
6. Средства коммуникации.
	- Позволяют установить соединения между компьютерами, обслуживают передачу сообщений, обеспечивают возможность видеосвязи и т. д.
7. Средства обеспечения компьютерной безопасности.
	К ним относятся:
	- средства пассивной и активной защиты от повреждения;
	- средства защиты от несанкционированного доступа, просмотра и изменения данных.

### Инструментарий технологий программирования

Разработка [[ИТП|программного обеспечения]] — это сложный процесс, основной целью которого является создание и сопровождение программного кода, обеспечивающего необходимый уровень надёжности и качества продукта.

**Средства для создания приложений.** Включают в себя:

- локальные средства выполнения отдельных работ для создания программ;
- интегрированные среды разработки программ, обеспечивающие выполнение комплекса взаимосвязанных работ по созданию программ.

**Средства для создания информационных систем ([[CASE-технологии]]).**

- Представляют методы анализа, проектирования и создания программных систем и предназначены для автоматизации разработки и реализации [[Информационные системы|информационных систем]].

### Средства для создания приложений

[[Средства разработки|Локальные средства разработки]] включают в себя [[Язык программирования|языки]] и системы программирования, а также [[Инструментальная среда пользователя|инструментальную среду пользователя]].

[[Язык программирования]] — формальный язык для описания алгоритма решения задачи на компьютере.

С точки зрения синтаксиса все языки программирования делятся на следующие классы:

- **Машинные языки** — языки программирования, воспринимаемые аппаратной частью компьютера.
- **Машинно-ориентированные языки** — языки, которые отражают структуру конкретного типа компьютера (языки ассемблера).
- **Алгоритмические языки** — языки, отражающие структуру алгоритма.
- **Процедурно-ориентированные языки программирования** — языки с возможностью описания программ как совокупности процедур или подпрограмм.
- **Проблемно-ориентированные языки программирования** — языки, предназначенные для решения задач определённого класса.
- **Интегрированные системы программирования** — совокупность языка программирования и [[Виртуальная машина|виртуальной машины]], которая обеспечивает на реальной машине выполнение программ, написанных на данном языке.

[[Виртуальная машина]] — программный комплекс, имитирующий работу реальной машины с одним входным языком на другой машинный язык.

Виртуальная машина содержит [[Транслятор|транслятор]], [[Отладчик|отладчик]], компоновщик, включает в себя библиотеки стандартных подпрограмм и дополнительные сервисные средства программирования.

[[Транслятор]] — программа, обеспечивающая перевод текста с одного языка программирования на другой.

Трансляция может выполняться с использованием [[Компилятор|компиляторов]] или [[Интерпретатор|интерпретаторов]]: компиляторы транслируют всю программу без её выполнения, интерпретаторы выполняют пооператорную обработку и выполнение программ.

Программа, подаваемая на вход компилятора, называется исходной, а результат трансляции — объектной программой, которая дальше пригодна для обработки [[Редактор связей]].

[[Редактор связей]] — специальная программа, обеспечивающая получение загрузочного модуля, пригодного к выполнению.

[[Инструментальная среда пользователя]] предназначена для использования базовых программных сервисов в пакетах прикладных программ.
